System Architecture: The 4-Tier Routing Loop

Zero code changes for upstream developers via standard OpenAI/Anthropic API drop-in proxy.

TIER 01: REAL-TIME COMPLEXITY CLASSIFICATION <80ms LATENCY • $0.00003/Q

Incoming queries are scored across a normalized complexity scale (0.0 to 1.0) using lightweight token embeddings and task taxonomy rules (e.g. schema extraction vs. multi-step synthesis).

TIER 02: DYNAMIC ROUTING (SLM VS. FRONTIER) 78% SLM • 22% FRONTIER

Queries scoring < 0.65 are dispatched to Gemini 2.5 Flash / Llama 3.3 70B ($0.00078/q). High-complexity queries (≥ 0.65) route directly to Claude 3.5 Sonnet / GPT-4o ($0.00571/q).

TIER 03: CONFIDENCE & SCHEMA VERIFICATION ENTROPY GATING • P99 SAFETY

SLM outputs are parsed for JSON schema conformity and token logprob entropy. If confidence drops below safety thresholds or output validation fails, the query escalates transparently to the frontier tier.

TIER 04: PROMPT PREFIX CACHING 50%–90% INPUT TOKEN REBATE

Static system prompts, RAG schemas, and few-shot examples are cached in provider GPU memory, saving 80% on repeated input prefix costs across user conversational sessions.
