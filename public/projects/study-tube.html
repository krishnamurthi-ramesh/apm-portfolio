Problem Space • The Mobile Hotspot Penalty

“350M+ learners on 1.5–2.0 GB/day mobile hotspots burn their entire study allowance in under an hour because auto-bitrate treats static lectures like 1080p60 cinema.”

On uncapped fiber connections, auto-1080p60 (~25–35 MB/min) plus sidebar hover previews (~150–250 MB/hr) goes unnoticed. On capped cellular data across Tier-2/Tier-3 cities and emerging markets, learners need intentional visual fidelity matched to lecture type alongside distraction removal—without breaking YouTube ToS.

Subject-Aware Stream Governor Modes

Mapping cognitive legibility requirements directly to bitrate targets instead of one-size-fits-all compression.

Talk Mode (480p SD)

~65% Saved

Ideal for verbal seminars, founder talks, and large slide decks where high frame-rate 1080p adds zero comprehension gain.

Board Mode (720p HD)

~45% Saved

Preserves crisp whiteboard calculus derivations, system architecture sketches, and chemistry equations without 1080p60 overhead.

Code Mode (720p / 1080p)

~35% Saved

Guarantees pixel-crisp 12pt IDE syntax and terminal outputs while still suppressing background sidebar prefetch and hover previews.

Audio-First Mode (144p + Mask)

~85% Saved

Turns audio podcasts, PM interviews, and study soundtracks into ultra-low-data streams inside an uncluttered study canvas.
