04 / Mental Models

How I Think About Products

Five core operating heuristics honed through engineering and MBA product discovery. Click each card to reveal operational applications.

01 / Problem Framing expand_more

A technically impressive solution can still solve the wrong problem.

The hardest part isn't implementing vector search or fine-tuning models. It's verifying what should actually be measured and confirming the technical output directly empowers a high-frequency workflow.

💡 In Practice: At Meraqui, we paused LLM fine-tuning until we verified recruiter bottlenecks were caused by ERP schema mismatches, not resume phrasing.
Focus: Discovery > Velocity
02 / Metric Rigor expand_more

I don't trust a metric without understanding what changed.

A +15% improvement sounds great in a slide deck, but I interrogate what changed in underlying data distributions, eval methodology, and user workflows. Metrics start the investigation.

💡 In Practice: Precision gains can mask severe drops in recall on edge candidates. Always evaluate Recall@K alongside customer contact rates.
Focus: Causality > Correlation
03 / Explicit Trade-offs expand_more

What are we gaining, and what are we giving up?

If an assumption can be de-risked with a small experiment or proxy test, I advocate doing so before committing engineering cycles. Product excellence is resource allocation.

💡 In Practice: Chasing 99% accuracy via agent chains inflates latency by 3x. For interactive UX, 98% with 400ms latency wins every single time.
Focus: De-risking > Overbuilding
04 / Intentional Friction expand_more

I don't assume every friction point deserves a feature.

Some friction is deliberate—like double confirmations that prevent catastrophic data loss or compliance guardrails that protect lending portfolios. Understand intent first.

💡 In Practice: Skippable KYC in fintech creates phantom growth. Real-time document parsing prevents downstream loan default and partner rejection.
Focus: Intentionality > Pure Ease
05 / The Lifecycle expand_more

The PR merge is day zero. Real learning starts now.

Shipping code is the starting line. True validation only commences once live telemetry feeds in and edge-case behavior manifests in user sessions.

💡 In Practice: Continuous drift monitoring and user feedback loops prevent catastrophic accuracy decay after production deploy.
Focus: Feedback Loops > Deployments
